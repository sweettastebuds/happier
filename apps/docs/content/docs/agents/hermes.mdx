Hermes Agent by Nous Research runs as a gateway process on your computer.
Happier connects to that gateway over the same WebSocket protocol Hermes's own
terminal UI uses (`hermes-gateway-v1`). It does not use ACP.

This agent is experimental and ships in the next Happier version.

## What you need first

Happier does not install Hermes for you. Install it yourself, then start your
Hermes gateway. Happier only attaches to a gateway that is already running. It
never starts, restarts, or stops one, so you must run your own gateway.

On Linux and macOS, one way to install it is with [uv](https://docs.astral.sh/uv/):

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
uv tool install hermes-agent
```

This puts `hermes`, `hermes-acp`, and `hermes-agent` in `~/.local/bin`, which
Happier finds without any configuration. You can also use Hermes's own installer
or, on Windows, the install path in the
[official repository](https://github.com/NousResearch/hermes-agent).

Happier asks the `hermes` CLI for a one-time connection ticket
(`hermes -p <profile> gateway attach --json`) every time it connects. If no
gateway is running, or it is starting, draining, inaccessible, on a different
profile, or incompatible, Happier tells you so and asks you to start or update
your Hermes gateway.

## Profiles

You choose a Hermes profile when a session starts. The session keeps that
profile and resume always uses it; you cannot switch profiles inside a session.

## Permissions

Hermes decides which actions need approval through its own `approvals.mode`
setting. Happier only answers the approval prompts Hermes raises: the default
mode asks you each time, and yolo approves them automatically. Happier does not
enforce read-only or sandbox behavior for Hermes, so it offers only the default
and yolo permission modes. Approving "for this session" is remembered by Happier per exact command; edits, commands Hermes redacts, and approvals
that do not name a concrete command are approved once.

## Start and resume sessions

```bash
happier hermes
```

Happier supports fresh and resumed sessions, streaming replies and reasoning,
tool activity, approvals, clarifying questions, interrupt, steering, and model
selection. Only the slash commands the gateway supports are offered.
